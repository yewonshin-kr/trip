# 삿포로 Trip Log PWA

안드로이드 Chrome에서 홈 화면에 설치해 사용하는 정적 웹앱입니다.

## 공개 GitHub 저장소에 올리는 파일

이 폴더 안의 앱 파일만 GitHub Pages 저장소 최상위에 업로드합니다.

- `index.html`: 앱 화면 구조
- `styles.css`: 화면 스타일
- `app.js`: 일정·준비물·가계부 및 JSON 가져오기 로직
- `sw.js`: 오프라인 캐시
- `manifest.webmanifest`, `icons/`: 홈 화면 설치 설정

**공통 여행 JSON과 개인 JSON은 이 폴더에 포함되어 있지 않으며 GitHub에 올리지 않습니다.**

이전 버전에서 `data/trip-data.json`을 GitHub에 올렸다면 저장소에서 해당 파일과 `data` 폴더를 직접 삭제해 주세요. 새 ZIP을 덮어쓰는 것만으로는 기존 GitHub 파일이 자동 삭제되지 않습니다.

## GitHub Pages 배포

1. 이 폴더 안의 파일과 하위 폴더를 저장소 최상위에 업로드합니다.
2. **Settings → Pages → Deploy from a branch**를 선택합니다.
3. Branch는 `main`, 폴더는 `/(root)`로 설정합니다.
4. 생성된 Pages 주소를 안드로이드 Chrome에서 연 뒤 홈 화면에 추가합니다.

## 동행자에게 공유할 파일

GitHub Pages 주소와 함께 다음 파일을 별도로 전달합니다.

- `sapporo-trip-shared-data.json`
  - 여행명과 기간
  - 항공편
  - 숙소명·객실·주소
  - 숙소 예약번호와 맵코드
  - 체크인·체크아웃 안내
  - 투숙객 정보 제출 링크와 안내

동행자는 앱에서 다음 순서로 파일을 불러옵니다.

**기타 → 공통 여행 데이터 불러오기 → `sapporo-trip-shared-data.json` 선택**

공통 JSON은 한 번 불러오면 해당 휴대폰의 Chrome 저장소에 유지됩니다. GitHub 서버로 업로드되지 않습니다.

## 개인 데이터

다음 데이터는 각자 별도로 관리합니다.

- 일정
- 준비물 카테고리와 항목
- 날짜별 코디
- 가계부와 예산

기존 개인 데이터를 이어서 사용할 사람은 앱에서 다음 순서로 복원합니다.

**기타 → 개인 데이터 복원 → 개인 JSON 선택**

앱에서 **기타 → 개인 데이터 백업**을 누르면 `sapporo-trip-personal-data.json` 형식으로 다시 저장할 수 있습니다.

## 주요 기능

- 일정 화면에서 좌우 스와이프로 날짜 변경
- 준비물 카테고리 추가·명칭/아이콘 변경·삭제
- 일정·준비물·가계부 자동 로컬 저장
- 공통 여행 데이터와 개인 데이터의 분리 가져오기
- 홈 화면 설치와 오프라인 실행

## 데이터 적용 규칙

- 공통 여행 JSON을 불러오면 여행·항공편·숙소/체크인 정보만 변경됩니다.
- 개인 JSON을 복원하면 일정·준비물·코디·가계부만 변경됩니다.
- 한 파일을 불러와도 다른 영역의 데이터는 유지됩니다.
- **현재 기기 데이터 초기화**를 누르면 불러온 공통 데이터와 개인 데이터가 모두 삭제됩니다.

## 데이터 유지 주의사항

- 같은 Chrome과 같은 GitHub Pages 주소로 사용하세요.
- Chrome의 사이트 데이터 또는 앱 데이터를 삭제하지 마세요.
- 시크릿 모드에서는 사용하지 마세요.
- 개인 데이터는 여행 중 한두 번 백업하는 것을 권장합니다.
