# 삿포로 Trip Log PWA

안드로이드 Chrome에서 홈 화면에 설치해 사용하는 공유용 정적 웹앱입니다.

## 파일 구조

- `index.html`: 최소 HTML 구조
- `styles.css`: 화면 스타일
- `app.js`: 일정·준비물·가계부 로직
- `data/trip-data.json`: 공유할 여행 기본 정보와 항공편
- `sw.js`: 오프라인 캐시
- `manifest.webmanifest`, `icons/`: 홈 화면 설치 설정

## GitHub Pages 배포

1. 이 폴더 안의 파일과 하위 폴더를 저장소 최상위에 업로드합니다.
2. **Settings → Pages → Deploy from a branch**를 선택합니다.
3. Branch는 `main`, 폴더는 `/(root)`로 설정합니다.
4. 생성된 Pages 주소를 안드로이드 Chrome에서 연 뒤 홈 화면에 추가합니다.

## 공유 데이터와 개인 데이터

### GitHub에 올리는 공통 데이터

`data/trip-data.json`에는 다음 데이터만 초기값으로 포함됩니다.

- 여행명과 여행 기간
- 항공편
- 통화와 공개 가능한 안내 메모

### 각 휴대폰에서 관리하는 개인 데이터

다음 데이터는 공통 JSON에 포함하지 않습니다.

- 일정
- 준비물 카테고리와 항목
- 날짜별 코디
- 가계부와 예산
- 숙소 주소, 객실, 예약번호, 투숙객 제출 링크

본인 데이터는 별도로 제공된 `sapporo-trip-personal-backup.json`을 **기타 → 백업 데이터 복원**에서 선택해 가져옵니다. 이 파일은 GitHub에 업로드하지 마세요.

다른 사람은 처음 접속했을 때 일정과 준비물이 비어 있으며, 각자 추가한 데이터는 각자의 휴대폰 브라우저 `localStorage`에만 저장됩니다.

## 주요 기능

- 일정 화면에서 좌우 스와이프로 날짜 변경
- 준비물 카테고리 추가·명칭/아이콘 변경·삭제
- 일정·준비물·가계부 자동 로컬 저장
- 전체 데이터 JSON 백업·복원
- 홈 화면 설치와 오프라인 실행

## 업데이트 시 데이터 동작

- 같은 GitHub Pages 주소와 같은 Chrome을 계속 사용하면 기존 로컬 데이터가 공통 기본값보다 우선합니다.
- 기존 데이터를 초기화하고 공개 기본값부터 시작하려면 **기타 → 현재 여행 삭제**를 사용합니다.
- 이전 버전을 방문한 사람이 이미 데이터를 저장했다면 그 사람의 기존 일정과 준비물도 계속 남습니다.

## 데이터 유지 주의사항

- 같은 Chrome과 같은 GitHub Pages 주소로 사용하세요.
- Chrome의 사이트 데이터 또는 앱 데이터를 삭제하지 마세요.
- 시크릿 모드에서는 사용하지 마세요.
- 여행 중 한두 번 **기타 → 전체 데이터 백업**으로 JSON을 저장해 두는 것을 권장합니다.
