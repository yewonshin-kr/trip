# 삿포로 Trip Log PWA

안드로이드 Chrome에서 홈 화면에 설치해 일주일 동안 사용할 수 있도록 구성한 정적 웹앱입니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 파일과 `icons` 폴더를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.
6. 표시된 Pages 주소를 안드로이드 Chrome에서 엽니다.
7. Chrome 메뉴의 **홈 화면에 추가** 또는 페이지의 **기타 → 홈 화면에 설치**를 선택합니다.

## 첫 실행 후

- **기타 → 비공개 숙소 정보**에서 숙소명, 주소, 예약번호, 지도 링크 등을 입력합니다.
- 이 정보는 GitHub 파일에 기록되지 않고 해당 휴대폰의 브라우저 저장소에만 저장됩니다.
- 일정, 준비물, 가계부도 변경 즉시 같은 저장소에 자동 저장됩니다.
- 비공개 정보까지 포함한 백업은 **기타 → 전체 데이터 백업**에서 JSON 파일로 받을 수 있습니다.

## 데이터 유지 주의사항

- 같은 Chrome과 같은 GitHub Pages 주소로 사용하세요.
- Chrome의 사이트 데이터 또는 앱 데이터를 삭제하지 마세요.
- 시크릿 모드에서는 사용하지 마세요.
- 여행 중 한두 번 백업 JSON을 저장해 두는 것을 권장합니다.

## 공개 범위

GitHub Pages는 공개 주소입니다. 이 구성에서는 정확한 숙소 주소, 객실, 예약번호와 제출 링크를 HTML 기본값에서 제거했습니다. 다만 여행 날짜와 일정 등 나머지 콘텐츠는 페이지 소스에 포함되어 있으므로 공개되어도 괜찮은 정보인지 업로드 전에 확인하세요.

`robots.txt`와 `noindex` 메타 태그를 포함했지만, 이는 검색 노출을 줄일 뿐 접근을 차단하는 기능은 아닙니다.
